# CVMatch AI Bot

Telegram-бот для анализа резюме и сравнения его с вакансией с помощью AI.

## Возможности

- загрузка резюме текстом или PDF;
- сравнение резюме с вакансией;
- процент совпадения;
- подходящие и недостающие навыки;
- рекомендации по улучшению резюме;
- генерация сопроводительного письма;
- история анализов;
- сохранение данных в PostgreSQL.

## Стек

- Python
- aiogram
- Gemini API
- PostgreSQL
- Neon
- pypdf

## Запуск

1. Установить зависимости:

```bash
pip install -r requirements.txt
```

2. Создать .env:
```bash
BOT_TOKEN=
GEMINI_API_KEY=
DATABASE_URL=
```
3. Запустить бота:
```
python main.py
```
